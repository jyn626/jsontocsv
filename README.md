# JSONtoCSV 📝
a simple program to convert a JSON file into CSV, made for learning purposes.

## How to Use
1. Place your JSON file in the input folder, and run the program.
2. The CSV result is stored in the output folder.

## Constraints
-	Nested JSON structures are not supported.
-	There's definitely better ways for my solutions.
